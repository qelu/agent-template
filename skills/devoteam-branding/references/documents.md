# Documents, reports, proposals, CVs, and document PDFs

## Construction

- Select the current official long document, short document, CV, white-paper, or one-pager template
  that matches the deliverable. Do not force content into the wrong template to save time.
- Copy the complete native template before editing. Preserve named styles, section architecture,
  page furniture, headers, footers, lists, tables, image frames, and intentional page breaks.
- For DOCX delivery, prefer editing or exporting the approved native source. Use Aptos only when
  Microsoft Office compatibility makes Montserrat impractical.
- For a PDF deliverable, author and validate the editable source first, then export to PDF.
- Never guess personal facts in CVs or retain example names, employers, dates, projects, skills, or
  company statistics.

## Content fit

- Use native heading and list styles; never type bullet glyphs manually.
- Preserve a concise hierarchy, readable line length, and consistent paragraph spacing.
- Shorten flexible wording or choose a better template before shrinking body text excessively.
- Keep tables within page bounds and repeat header rows when appropriate.
- Update time-sensitive company facts from an authoritative current source or remove them.
- Retain required legal, confidentiality, accessibility, and document-control information.

## QA

Render the final document to PDF and inspect every page. Check title treatment, headers and footers,
widows and orphans, list indentation, page breaks, table splits, image proportions, links, heading
consistency, reading order, and remaining placeholders. Compare the native document and exported
PDF so export did not substitute fonts, move objects, or drop content.
