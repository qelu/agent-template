# Spreadsheets

## Construction

- Copy the current official workbook template before editing.
- Preserve workbook theme, formulas, validation, conditional formatting, named ranges, charts,
  filters, frozen regions, hidden structure, and number formats.
- Keep data types and locale-aware date, percentage, currency, and unit formats intact.
- Use restrained header bands, section fills, and borders. Prefer spacing and alignment over heavy
  gridlines.
- Freeze useful header rows or identifier columns for long operational tables.

## Brand application

- Use Montserrat for native Google Sheets and the approved Office fallback when required.
- Use Dark Grey for ordinary text and Red Poppy only for a key header, callout, exception, or KPI.
- Use secondary colors for fills, not text.
- Use accent colors for distinct data series. Do not make every series Red Poppy.
- Pair color-coded states with labels, symbols, or direct annotation.
- Keep comparable charts on consistent scales and avoid 3D effects, gradients, and decorative
  legends.

## QA

Inspect every used range, not only the first viewport. Check formulas and errors, validation,
filters, frozen panes, hidden rows and columns, print areas, charts, conditional formats, overflow,
heading visibility, numeric alignment, and accessibility. Confirm the workbook opens in the
requested native format and contains no sample data or unused placeholder sheet.
