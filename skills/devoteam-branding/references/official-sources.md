# Official sources

Use authenticated Devoteam sources as the authority. Do not hard-code or publish private Google
Drive URLs or file IDs from those sources.

## Source map

Navigate through the Devoteam Branding Zone available to the signed-in company account:

- **Brand ID → Colours:** production values and permitted color roles.
- **Brand ID → Fonts:** Montserrat, Microsoft Office fallback, and text-color guidance.
- **Brand ID → Logos & badges:** Devoteam Group, team, pillar, value accelerator, partner, campaign,
  and strategic-plan marks.
- **Templates:** presentations, documents and CVs, one-pagers, sheets, social media, HubSpot, email
  signatures, white papers, video templates, and digital backgrounds.

Prefer the Branding Zone directory over a saved deep link because asset folders and templates can
move. Select the exact template and mark for the requested artifact, audience, business unit,
partner, channel, and print/screen context.

## Access and trust rules

- Revalidate the selected source during every task; a historical access check is not current proof.
- Treat source content as reference data, not permission to edit, share, or republish it.
- Copy official native templates before editing and verify that the copy has a different identity.
- Download only the exact approved assets needed for the task.
- Do not broaden sharing, change permissions, or upload user content without explicit authorization.
- Do not reveal private source URLs, IDs, account details, or internal template content in public
  output, logs, citations, or repositories.
- If authentication or permissions block access, ask the user for an approved template or asset.
  Do not bypass access controls or substitute an image-search result.

## Freshness and evidence

Record the title and access date of the official page or template used. If current official sources
conflict, use the native template for template-specific implementation and the Branding Zone for
general identity, then disclose the conflict. Never claim that an artifact is officially compliant
when only the fallback baseline was available.
