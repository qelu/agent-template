# Evidence gathering

1. List the claims that affect the decision.
2. Prefer direct inspection for local state and official or primary sources for external facts.
3. Check dates, versions, scope, and conflicts between sources.
4. Separate FACT, INFERENCE, RECOMMENDATION, and UNKNOWN.
5. Cite the source nearest the supported claim when citations are useful.
6. Stop searching when additional evidence would not change the decision.

Never manufacture certainty. Avoid loading broad reference collections when a targeted document or query is sufficient.
