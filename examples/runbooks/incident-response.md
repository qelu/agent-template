# Runbook: Incident response

1. Stabilize: prevent additional harm without destroying evidence.
2. Scope: identify affected resources, time window, and user impact.
3. Preserve: capture relevant logs and state in an approved location.
4. Recover: use the safest tested restoration path.
5. Validate: confirm service and security health.
6. Learn: record facts, contributing conditions, and follow-up actions.

Never rotate credentials, delete data, or contact external parties without the authority required by policy.
